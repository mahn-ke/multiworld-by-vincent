Path to the goal

    

    
One line per player. Columns are spheres: everything in a column can be found once the earlier columns are found.
      Each box is a progression item that player receives. A dot with an arrow coming from another player's line means that player has to find it for them. ◆ marks the goal. Found items fade out. Hover a box for details.

Unlock this now?

  

  
This permanently marks the location as found and sends its item to the receiving player.
    Unchecking is not supported. Games may keep unlocks, items, or other effects even if server progress is reset.

  

  



  
Start a new seed?

  
This will reset progress, randomize items and require players to reconnect.

  
The current game server keeps running while the new seed generates. If generation fails, nothing changes.
